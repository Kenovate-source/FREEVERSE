# Database schema

Generated by `node scripts/gen-docs.mjs` from `migrations/sqlite/*.sql` (the PostgreSQL files are rendered from the same templates; types differ: UUID/TIMESTAMPTZ/JSONB/BOOLEAN on PostgreSQL, TEXT/INTEGER on SQLite). Source of truth: `migrations/src/*.sql.tpl`. A test fails if the rendered files are stale.

PostgreSQL production notes: row-level security is enabled on every table with **no policies**, so the PostgREST/Supabase anon and authenticated roles can read nothing; only the server's own database role can. The audit log is append-only, enforced by triggers.
